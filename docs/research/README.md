# Pesquisa de origem

Este projeto nasce da pesquisa Android/IA/estúdio visual de 2026-10-05 no
FNaF e da experiência de operação Pokémon na mesma sessão.

As cópias de pesquisa são snapshots documentais, não código nem capacidades
qualificadas. Seus links relativos referem-se à árvore original do FNaF.
O registro `provenance.json` retém caminho, revisão e SHA-256 de origem. O
relatório de estúdio ainda não estava commitado no checkout de origem quando
foi consumido; a revisão do Git identifica a árvore base, e o hash identifica
os bytes efetivamente lidos.

A diretriz posterior de Pedro autoriza iniciar este repositório, consumir
a infraestrutura FNaF e usar o FNaF como primeiro consumidor. Ressalvas dos
snapshots sobre uma migração ainda não autorizada descrevem o momento da
pesquisa e não substituem essa decisão posterior.
